## 真实 AI 核验

1. 产品订单金额、生产良品率分析：生成柱状图、饼图、明细表；图表金额与独立 SQL 聚合一致，CSV 导出成功。
2. 采购入库技能：模型读取技能并创建采购单、确认收货，M002 库存精确增加 400kg，仅入库一次。
3. 接单排产技能：创建 C001/P001/120米订单，在 MC02 排产并下达；棉纱按 BOM 扣减 21.6kg。
4. 多轮上下文与质检发货：只说“刚才的工单/订单”，模型正确关联单据；报工合格118米、不合格2米，并发货118米，成品净库存保持一致。
5. 补产补发：新建2米补产工单，领料、合格报工、发货后订单为 `shipped`。所有11个业务动作都有审计记录。
6. 自定义技能：通过配置接口新增分析技能，模型读取并保存指定标题的质量报告。
7. 禁用技能：禁用后模型停止执行，没有新报表或流程副作用。
8. 预制晨报：在当前演示主库检查交期、原料、在制和质量，真实生成异常明细表与产品金额柱状图，业务审计仍为空。

接口级验收另外覆盖全部8种报表类型、SQL写入拒绝、内部服务令牌、同源写操作保护、关闭两个服务、重新启动后的业务/对话/报表持久化。
