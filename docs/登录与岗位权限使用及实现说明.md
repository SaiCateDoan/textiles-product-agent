# 登录与岗位权限

## 使用

运行 `start.cmd` 后访问 `http://127.0.0.1:8765`。未登录时仅显示登录页。第一次升级会保留原数据库，为管理员、经理、销售、生产、仓库、采购、财务生成7个演示账号；随机初始密码保存在本机 `data/demo-accounts.json`，不进入 Git。修改密码后，该文件中的初始密码不再有效。

使用 `admin` 登录后，进入“账号与权限”：

1. 新建账号、选择岗位、设置至少10位密码。
2. 销售等客户范围岗位填写负责客户编号，例如 `C001,C002`；空列表表示无负责客户。
3. “配置读写权限”可勾选数据表中的字段、可执行业务，以及全范围或客户范围。业务命令要求相应基础表和编号字段，保存时会验证依赖。系统管理员岗位不可修改，必须保留至少一个启用的管理员。
4. 修改账号、密码或岗位授权会撤销受影响账号的现有登录；重新登录后看到新的工作台。页面每30秒及回到前台时重新检查会话，任何接口调用也立即校验。

网页的全局关闭仅对管理员展示。其他岗位有“退出登录”，只结束自己的登录。本机 `stop.cmd` 是机器维护者的停止入口，直接向本项目管理进程发送停止请求。

## 权限边界

- **身份**：账号密码使用带随机盐的 scrypt 哈希；随机会话仅在 HttpOnly、SameSite=Strict Cookie 中传递，数据库保存会话令牌摘要。会话有效期8小时，有失败登录限流。写接口校验与会话绑定的 CSRF 令牌及 Origin，服务仅监听环回地址。
- **前端**：总览按可读字段生成指标；数据页仅列授权表，表格仅包含授权字段；业务表单仅列可执行命令。账号管理、技能编辑、全局关闭均仅管理员可见。切换账号清空工作区、弹窗、图表和报表草稿；会话选择按账号独立保存。
- **Agent**：每轮模型调用与工具调用重新校验登录；写工具集合、字段目录、技能清单依岗位生成。未授权业务不能通过模型调用或提示词扩大权限。
- **私有适配层**：ERP/MES 请求必须同时带管理进程生成的内部令牌与有效用户会话摘要；后端从账号数据库解析身份，不接受客户端声称的岗位。
- **只读 SQL**：SQLite先在仅含授权字段的空结构上编译查询，确认实际引用的表；只加载这些表的授权记录，再在临时内存数据库中执行。没有跨请求权限或数据缓存。`SELECT *`、JOIN、CTE、聚合和 `main.orders` 都不能触及被排除的数据。原有只读 SQLite authorizer、查询预算和500行结果上限保留。
- **客户范围**：客户、订单及其关联工单、报工、发货按分配客户过滤；产品/BOM属于公共主数据。客户范围岗位不能授权无对应客户归属的库存流水、采购、审计等表。
- **写入**：业务命令检查操作权限及目标客户范围，返回值也按字段权限裁剪。流程在执行前检查所有步骤的操作权限，并在同一事务内检查每个目标；任一步越权或业务失败全部回滚。幂等键按用户隔离，授权策略变化时同一键的旧请求会被拒绝复用，避免重放泄露或重复落单。审计增加操作账号。
- **私有结果**：聊天、消息、运行轨迹、报表及 CSV 同时检查账号与权限策略指纹。权限范围变化后旧范围的结果隐藏，原记录不删除；管理员也不能通过普通聊天/报表接口访问其他账号私有结果。升级前已有聊天与报表迁移归管理员。
- **技能**：声明式流程必须拥有全部步骤权限才能使用；指令型技能通过 `required_tables` 声明数据依赖。未声明依赖的纯指令技能只供管理员使用。技能文本无权绕过业务/查询权限。

岗位权限限制通过系统接口获得的数据，不能撤回用户此前已经下载的文件。本地文件和进程的所有者可以直接维护 SQLite、源码及启动器；此版本是单机多岗位演示，不是隔离本机管理员的安全沙箱。

## 接口变化

- `POST /api/auth/login`：JSON `username/password`，要求 `X-Demo-Login: 1`，成功设置会话 Cookie。
- `GET /api/bootstrap`：登录后返回用户、岗位策略、授权命令和该会话 CSRF 令牌。
- `POST /api/auth/logout`：撤销当前登录，要求 `X-Demo-Token`。
- `GET /api/admin`、`PUT /api/admin/users/{id}`、`PUT /api/admin/roles/{id}`：管理员账号和岗位维护。
- 所有其他业务、Agent、报表、技能接口均要求登录；`/api/health` 仅用于启动健康检查，保持匿名可用。
- `GET /api/dashboard` 改为按岗位返回 `cards` 与 `sections`，不生成无权限的指标。
